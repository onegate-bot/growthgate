# TikTok B2B Search SEO (EXP-001)

## Overview
Based on Enso Lab's empirical study (*TikTok Search SEO: 720+ B2B views in 28 days*, filed Sep 02, 2026). High-intent B2B problem queries on TikTok frequently lack relevant short-form video results, creating an organic search capture window.

## Protocol Steps
1. **Identify Keyword Seams:** Extract search queries where autocomplete suggests B2B workflows/tooling but current top video results are generic or consumer-focused.
2. **On-Screen & Metadata Alignment:**
   - Anchor the exact search phrase within the first 3 seconds of spoken audio and on-screen caption hook.
   - Use clean, keyword-dense video descriptions without generic hashtag spam.
3. **Conversion Funneling:** Direct search viewers to an open-source repo, developer documentation, or specific interactive tooling via pinned comments and profile links.
